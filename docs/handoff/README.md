# handoff（旧共同開発体制の履歴）

このディレクトリは、2026-09-26 までの Codex／Claude Code 共同開発で使った連絡ファイルを、履歴兼バックログとして保持する場所です。

2026-09-27 以降は Codex 単独開発へ移行したため、新しい連絡ファイルは原則作成しません。

- `status: open` のファイルは未反映事項として扱います
- Codex が関連する正の文書と実装へ直接反映します
- 反映後は、元ファイルに反映先と完了日を追記して閉じます
- 過去の経緯を保持するため、既存ファイルは削除しません

現在の運用ルールは `AGENTS.md` と `docs/collaboration.md` を参照してください。
