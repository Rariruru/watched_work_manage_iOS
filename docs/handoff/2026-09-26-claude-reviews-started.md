## 何が起きたか
Codex から意見が無かったので、上田の指示で、今回も**実装計画なしで**「感想・評価」を実装した（`collaboration.md` §3 の例外）。
前の連絡ファイル `2026-09-26-claude-foundation-started.md` は、まだ回答が無い。

上田が決めたこと（2026-09-26）:
- **評価の刻みは 1〜5 の整数**。映画・シーズン・各話で共通
- **アニメ・ドラマを映画に変えたとき、映画は「観た」・未評価・感想なしで始める**（前の連絡ファイルの提案3への答え）

実装したもの:
- 映画・シーズン全体の評価・感想・視聴状態・視聴日の編集（1つの画面を共用）
- 各話の評価・一言感想（シーズン詳細から話を押すとシートが出る）
- 話数を減らして評価の付いた話が範囲外になるときの確認（基準27）。範囲外の話の評価は DB が消す
- 種別を変えたときに、評価・感想も一緒に移す・消す（基準31・32）
- 一覧の★（映画の行・「シーズンごと」の行。「作品ごと」のアニメ・ドラマの行には出さない）
- DB: `supabase/migrations/20260926010000_reviews_and_episodes.sql`（未適用。適用は上田）

## 提案（Codex に反映してほしいこと）
1. **`requirements.md` §7**: 「評価の刻み」を決定済みに移す（1〜5 の整数、シーズンと各話で同じ。2026-09-26 上田）。変更履歴にも書く
2. **`contracts.md`「種別の変更」**: 「映画の評価・感想・視聴状態・視聴日は空で始まる」を「視聴状態は『観た』、評価・感想・視聴日は空で始まる」に直す（2026-09-26 上田）
3. **`contracts.md`「話」**: 実装では次のようにした。契約として書いてほしい
   - 評価か一言感想のどちらかがある話だけを記録する。両方を外すと、その話の記録を消す（未評価に戻る）
   - 話の番号はシーズンの話数の範囲内だけ。話数を減らすと、範囲外の話の記録は消える
4. **`contracts.md`「視聴状態・視聴日」**: 視聴日は `YYYY-MM-DD`（実在する日付）か、空。入力欄に「今日」ボタンがある。時刻とタイムゾーンは持たない
5. 感想・一言感想の文字数の上限は設けていない。要るなら決めてほしい

## 追記（2026-09-26、上田の追加の依頼）
**決定の変更**: 前は「作品全体（全シーズンをまとめた）の評価は持たない」「平均は出さない」（`requirements.md` 非スコープ）だった。上田の依頼で次のように変えた。
- アニメ・ドラマの作品全体の評価: **既定は評価の付いたシーズンの平均**（小数第1位まで、四捨五入。未評価のシーズンは数えない。全部未評価なら「未評価」。1シーズンならそのシーズンの評価）。作品詳細で**手動でも付けられ**（1〜5 の整数）、「平均に戻す」で平均に戻る
- 平均は保存しない。手動の評価だけを `works.rating` に保存する（映画の評価と同じ列。アニメ・ドラマのときは「手動の評価」の意味）
- 「作品ごと」表示のアニメ・ドラマの行に、作品全体の評価を出す（手動なら★、平均なら「★ 4.5（平均）」）
- 各話に**タイトル（任意）**を足した。タイトルがあれば「第3話 南西へ」と出す。タイトルだけの話も記録に残す。話数を減らすと範囲外の話のタイトルも消える
