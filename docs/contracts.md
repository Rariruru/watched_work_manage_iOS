# データ契約

**ここが正。** 単位・綴り・省略すると潰れるフィールド・集計の定義は、決まり次第ここに書く。
コード・`requirements.md` と食い違ったら、ここを直してから両方を合わせる。
決定を変えたら、古い記述を消さずに「変更: YYYY-MM-DD 理由」を残す。

## 用語
> 多義的な語は勝手に解釈せず、ここで定義を固定する。変更: 2026-09-26 `CLAUDE.md` の用語集をここへ移した（Codex も読むため）
- 聖地巡礼: 作品の舞台・ロケ地を実際に訪れること。1回の訪問を記録1件として残す
- 記録: 作品に紐づく写真付きの記録。種類は聖地巡礼 / グッズ / イベントの3つ。「感想・評価」とは別物
- シーズン: アニメ・ドラマの作品の下のまとまり。評価・感想・視聴状態・視聴日はシーズン単位で持つ。映画はシーズンを持たない
- 作品全体の評価: アニメ・ドラマでは、手動評価があればその値、なければ評価済みシーズンの平均を表示する。作品全体の感想は持たない
- 各話の評価: シーズンの評価とは独立。シーズンの評価を各話から計算しない
- 投稿: 次段階の「他の利用者に公開すること」だけを指す。今回の「記録」（本人だけが見る保存）とは区別する

## 列挙値
- 作品の種別: `anime`（アニメ）/ `drama`（ドラマ）/ `movie`（映画）の3値
- 視聴状態: `want`（観たい）/ `watching`（観ている）/ `watched`（観た）の3値。新しく作るときの既定は `watched`
- 記録の種類: `pilgrimage`（聖地巡礼）/ `goods`（グッズ）/ `event`（イベント）の3値

## 構造
```
作品（タイトル・種別・[アニメ／ドラマ] 作品全体の手動評価）
├─ [アニメ・ドラマ] シーズン（1つ以上）
│    ├─ シーズンの評価・感想・視聴状態・視聴日
│    └─ 話（第1話〜第N話）: タイトル・評価・一言感想
├─ [映画] 作品の評価・感想・視聴状態・視聴日
└─ 記録（聖地巡礼 / グッズ / イベント）: 名前・日付・写真・メモ・位置
```

- 変更: 2026-09-27 アニメ・ドラマの作品全体の評価と各話タイトルを追加した。作品全体の評価は評価済みシーズンの平均を既定とし、手動評価だけを作品に保存する

## 作品
- タイトル: 必須。空文字は不可
- 重複の判定: 同じ利用者の中で「タイトルが一致 かつ 種別が一致」。警告するだけで、登録は許す
  - 現行実装は前後の空白を除いた完全一致。全角半角・大文字小文字を同一視するかは未定
- 作品を削除すると、その作品のシーズン・話の評価・感想・記録・写真もすべて消える
- ⚠️ 種別の変更（決定: 2026-09-26、ワイヤーフレーム第2版の差し戻し A）
  - アニメ ⇄ ドラマ: シーズン・話はそのまま
  - アニメ・ドラマ → 映画: 確認を出し、確定したらシーズンと話をすべて消す。映画は視聴状態 `watched`、評価・感想・視聴日は値なしで始まる
  - 映画 → アニメ・ドラマ: 「シーズン1」（話数 0）を作り、映画の評価・感想・視聴状態・視聴日をシーズン1に移す
  - どの変更でも、聖地巡礼・グッズ・イベントの記録は残す

## シーズン（アニメ・ドラマのみ）
- 作品の追加時に「シーズン1」を1つ作る。アニメ・ドラマの作品はシーズンを必ず1つ以上持つ
- シーズン名: 必須。既定は「シーズンN」（N は作品内での並び順）。「第2期」「2nd season」などに書き換えてよい
- 並び順: 作成順。並べ替えは今回しない
- 話数: 0 以上の整数。0 のときは話が並ばない。話数 N のとき第1話〜第N話が存在する
- ⚠️ 話数を減らして、タイトル・評価・一言感想のある話が範囲外になるときは確認を出す。確定したら範囲外の話の記録を消す
- シーズンの評価は、話の評価から**計算しない**
- 最後の1シーズンは削除できない（削除ボタンを出さない。作品ごと削除する）。決定: 2026-09-26、差し戻し B

## 話
- 番号: 1〜話数 の整数。番号に当てはまらない話（総集編・OVA 等）: 未定
- タイトル: 任意。前後の空白を除いて保存し、空なら値なし
- 評価: 1〜5 の整数、または「未評価」
- 一言感想: 任意。前後の空白を除いて保存し、空なら値なし
- タイトル・評価・一言感想のいずれかがある話だけを記録する。3つとも値なしにすると話の記録を削除する
- 話数を減らすと、新しい話数の範囲外にある話の記録は削除する

## 評価
- 映画・シーズン・話・作品全体の手動評価は1〜5の整数、または「未評価」（値なし）。**0 を「未評価」の意味に使わない**
- アニメ・ドラマの作品全体の表示評価:
  1. 作品に手動評価があれば、その整数を表示する
  2. 手動評価がなければ、評価済みシーズンだけの算術平均を小数第1位へ四捨五入して表示する
  3. 評価済みシーズンがなければ「未評価」と表示する
- 作品全体の平均は保存しない。アニメ・ドラマの `works.rating` は手動評価だけを表す
- 「平均に戻す」は作品の手動評価を値なしにする
- シーズンの評価は各話の評価から計算しない

## 視聴状態・視聴日
- 映画: 作品に1つ
- アニメ・ドラマ: シーズンに1つ。話ごとには持たない
- 視聴日は実在する日付を `YYYY-MM-DD` で持つか、値なしとする。時刻とタイムゾーンは持たない
- 作品一覧の「作品ごと」表示で視聴状態で絞り込むとき、アニメ・ドラマは「その状態のシーズンを1つ以上持つ作品」を一致とする

## 作品一覧の表示単位
- 「作品ごと」: 1作品1行。アニメ・ドラマの行は作品全体の表示評価・シーズン数・記録の件数。映画の行は評価・視聴状態
- 「シーズンごと」: アニメ・ドラマは1シーズン1行（行名は「作品タイトル シーズン名」）。映画は1作品1行のまま並ぶ
- 評価で並べ替えるときの表示単位: 未定

## 記録（聖地巡礼 / グッズ / イベント）
- 1記録は1作品に紐づく（シーズン・話には紐づけない）
- 保存後に記録の種類と紐づく作品は変更できない
- 名前: 必須（聖地巡礼＝場所名 / グッズ＝グッズ名 / イベント＝イベント名）
- 日付: 任意。入力欄の既定は今日。聖地巡礼＝訪問日 / グッズ＝入手日 / イベント＝開催日（参加日）
- 位置（緯度・経度）: 聖地巡礼とイベントだけが持てる。任意。位置の許可が無くても、地図で手動選択した値を入れられる
- 聖地巡礼の場所名が変わって入力が約1秒止まったら、端末OSのジオコーダーで検索し、最初の候補の緯度・経度をピンへ反映する。検索結果0件・失敗時は既存の位置を保持し、同じ名前で再検索できる。検索中の手動選択・現在地選択・位置の取り外しを、遅れて返った検索結果で上書きしない。イベント名とグッズ名は自動検索しない
- 記録詳細では写真を `position` の昇順で表示し、位置があれば保存した緯度・経度へピンを置いた地図を表示する。グッズと位置なしの記録には地図を表示しない
- 写真: 0〜4枚。入力ファイルは1枚10MB以下。アップロード前に長辺2048px以下へ縮小し、位置情報を含むEXIFを除去する
- 写真のStorageパス: `{user_id}/{record_id}/{photo_id}.jpg`。バケットは非公開とする
- 写真の一部アップロードに失敗している間は記録を保存済みにしない。未保存の入力と写真は画面内だけに保持し、キャンセル、端末の戻る操作、またはスワイプで閉じるときは破棄確認を出す。サーバー側の下書きは作らない
- メモ: 任意

## 所有と可視性
- すべての記録は作成した利用者だけが読み書きできる
- アカウント削除で、その利用者の作品・シーズン・話・記録・写真をすべて消す
- 次段階（公開投稿）の公開 / 非公開の単位: 未定
