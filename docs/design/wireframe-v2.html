観た作品と聖地巡礼の記録アプリ — ワイヤーフレーム

2026-09-26 時点（第2版）。実装の正ではありません。 要件の抜けを見つけるためのワイヤーフレームです。色・フォント・余白は決めていません。前提は iPhone 縦向き・ライト固定です。第2版で「シーズンと各話の評価」「作品ごと / シーズンごとの表示切り替え」「グッズ・イベントの記録」を足しました。第2版で増えた画面には NEW を付けています。A のような記号は、下の「差し戻し候補」の記号です。

画面遷移（主経路）

映画は作品詳細で評価します。アニメ・ドラマは作品詳細からシーズンに入り、シーズン全体の評価と各話の評価をそれぞれ付けます。聖地巡礼・グッズ・イベントの記録は、どの種別でも作品に紐づきます。

差し戻し候補（第2版）

シーズン・各話・グッズ・イベントを画面に並べて見つかった抜けです。データの形に関わるもの（A・B）は contracts.md にも書きます。

A

種別をアニメ・ドラマと映画の間で変えたとき、評価がどうなるか決まっていない

反映案映画に変えるときは「シーズンと各話の評価がすべて消えます」と確認を出し、確定したら消す。映画からアニメ・ドラマに変えるときは、映画の評価・感想・視聴状態・視聴日をそのまま「シーズン1」に移す。受け入れ基準に追加。

E-t

B

最後の1シーズンを削除できるかが決まっていない

反映案アニメ・ドラマは必ず1シーズン以上持つので、最後の1シーズンには削除ボタンを出さない（作品ごと削除する）。contracts.md には仮で書いてある。受け入れ基準に追加。

S-add

C

「作品ごと」表示で、アニメ・ドラマの行に何を出すかと、評価での並び替えが決まっていない

反映案作品全体の評価は無いので、行にはシーズン数と記録の件数だけを出す。Should の「評価で並び替え」は「シーズンごと」表示でだけ使えるようにする。

B

D

「シーズンごと」表示で映画がどう出るかが決まっていない

反映案映画は1作品1行のまま、シーズンの行と並べて出す。受け入れ基準28に追記。

B-s

E

話数を入れていないシーズンから、各話の評価に進めない

反映案話数が 0 のシーズン詳細では「話数が入力されていません」と「話数を入力」ボタンを出す。受け入れ基準に追加。

第1版の差し戻し（11件、反映済み）

  • 一覧の「＋」から記録を始められる
  • サインイン前に規約・ポリシーを読める
  • 追加時の視聴状態（既定は「観た」）
  • 作品のタイトル・種別を編集できる
  • 同じ作品の二重登録を警告する
  • 評価を「未評価」に戻せる
  • 視聴日を残せる
  • 記録の必須項目は名前だけ
  • 位置・写真の許可が無くても記録できる
  • 写真の一部失敗で「保存しました」を出さない
  • アカウント削除の失敗時の表示
