主な画面遷移

作品は入り口、シーズンと映画が感想・評価の単位、記録は作品に紐づく別の単位です。

A サインインApple でサインイン
B 作品一覧作品ごと / シーズンごと
C 作品追加映画、または初期シーズン
D 作品詳細シーズンと記録を振り返る
S / EP 評価シーズンは手動評価を優先し、なければ各話平均
M / F 記録作成作品を選び、3種類を作成
G 記録詳細閲覧・編集・削除
H / I 設定規約、サインアウト、アカウント削除

通常状態だけでなく、0件・絞り込み0件・読み込み失敗・通信なし・許可なし・破壊的変更の確認を分けています。
