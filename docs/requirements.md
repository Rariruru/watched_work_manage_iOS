# 要件定義：作品日和

作成日: 2026-09-26
更新日: 2026-10-04（各話からシーズン評価を自動算出。末尾「変更履歴」）

## 1. 目的
アニメ・ドラマ・映画を観た人が、作品（シーズン・各話）ごとの感想・評価と、その作品の聖地巡礼・グッズ・イベントの写真付きの記録を1か所に残し、あとから振り返れるようにする。
（公開投稿・他ユーザーとの共有は、利用者が増えてからの次段階。今回の記録データはそのまま公開投稿へ移行できる形で持つ）

## 2. 利用者と利用シーン
- 利用者: 不特定多数（App Store で公開）。アニメ・ドラマ・映画を観て、ロケ地・舞台を訪ねたり、グッズを集めたり、イベントに行ったりする人
- 使う場面:
  - 1話観終わった直後に、その話の評価と一言を残す
  - シーズンを観終わったときに、シーズン全体の評価と感想を残す
  - 聖地を訪れたその場で、写真と位置を記録する
  - 買ったグッズや、行ったイベントの写真を残す
  - 過去に観た作品・訪れた場所・集めたものを振り返る
- 使う頻度: 1話観るたび・聖地やイベントに行くたび（週に数回〜月に数回）

## 3. スコープ内の機能
### Must（これが無ければ成立しない）
- [ ] アカウント：Apple でサインイン・サインアウト・アカウント削除（削除すると本人の記録と写真もすべて消える）
- [ ] 作品とシーズンの登録：タイトルと種別（アニメ / ドラマ / 映画）、任意の作品画像1枚を入力して、自分の作品リストに追加する。アニメ・ドラマは作品の下にシーズンを持ち（追加時に「シーズン1」が1つでき、後から「シーズン2」などを足せる）、シーズンごとに話数を入力すると第1話〜第N話が並ぶ。作品のタイトル・種別・画像、シーズン名・話数は後から編集・削除できる。同じタイトル・同じ種別の作品が既にあるときは警告する
- [ ] 感想・評価の記録：
  - アニメ・ドラマ：**シーズンごと**の感想・視聴状態（観たい / 観ている / 観た。既定は「観た」）・視聴日（任意）と、**各話ごと**のタイトル（任意）・評価（1〜5の整数、任意）・一言感想（任意）を記録・編集・削除する。シーズン評価は、手動評価があればその整数を、なければ評価済み各話の平均（小数第1位）を表示し、「平均に戻す」で手動評価を外せる
  - アニメ・ドラマの作品全体：既定は評価済みシーズンの平均（小数第1位、未評価のシーズンは除外）を表示する。作品全体の評価を1〜5の整数で手動設定でき、「平均に戻す」で自動計算へ戻せる。作品全体の感想は持たない
  - 映画：作品ごとの評価・感想・視聴状態・視聴日を記録・編集・削除する
- [ ] 作品の写真付き記録：作品に紐づけて、**聖地巡礼・グッズ・イベント**の3種類の記録を作成・編集・削除する。どれも名前（場所名 / グッズ名 / イベント名、必須）・日付（既定は今日）・写真・メモを持ち、聖地巡礼とイベントは地図上の位置（任意）も持てる。聖地巡礼は場所名の入力から位置を自動検索できる。作品詳細からだけでなく、作品一覧の「＋」からも記録を始められ、作品はその場で既存から選ぶか新しく作れる。位置・写真の許可が無くても記録できる
- [ ] 振り返り：作品一覧を「作品ごと」と「シーズンごと」で切り替えて表示し、種別と視聴状態で絞り込む。作品詳細で、シーズン・各話の評価と、聖地巡礼・グッズ・イベントの記録をまとめて見る

### Should（あると価値が上がる）
- [ ] 作品の検索登録：外部の作品データベース（TMDB 等）でタイトル検索し、ポスター画像・公開年・シーズン・話数付きで登録する（手入力も残す）
- [ ] 聖地マップ：自分の聖地巡礼とイベントの記録を地図上のピンで一覧する。ピンから記録と作品へ移動できる
- [ ] 現在地から場所を入力：聖地巡礼・イベントの記録の作成時に、現在地を初期位置にする
- [ ] 並び替え：作品一覧を登録日 / タイトルで並べ替える。評価で並べ替えるときの表示単位は未決事項とする

### Could（余裕があれば）
- [ ] 写真の撮影日時・位置情報から、日付と場所を自動で埋める
- [ ] 作品一覧のタイトル検索
- [ ] 各話の「観た」チェックと、シーズンの視聴の進み具合（例: 8 / 12 話）
- [ ] 聖地巡礼の記録を、舞台になった話（第何話）に紐づける
- [ ] 記録一覧：作品をまたいで、グッズ・イベント・聖地巡礼の記録を種類別に並べる
- [ ] 統計（種別ごとの本数、評価の分布、訪れた聖地の数、グッズの数）

## 4. 非スコープ（今回はやらない）
- **公開投稿・他ユーザーの記録の閲覧・フォロー・いいね・コメント・通報**（利用者が増えてから次段階で入れる。聖地巡礼・グッズ・イベントの記録もすべて、今回は本人にしか見えない）
- 作品全体（全シーズンをまとめた）の感想
- 映画のシーズン・各話・シリーズのまとまり（映画は1作品＝1本）
- グッズの価格・購入店・在庫などのコレクション管理（名前・日付・写真・メモだけ）
- 各話ごとの視聴状態・視聴日（視聴状態と視聴日はシーズン単位）
- Apple 以外のログイン（メール・Google・X など）
- オフラインでの記録作成・編集（通信が無いときは「接続できません」を表示して保存しない）
- ダークモード（ライト固定。OS の設定に追従しない）
- iPad 最適化・横向き（iPhone の縦向きのみ）
- Android・Web 版
- 多言語対応（日本語のみ）
- アプリ内課金・広告
- プッシュ通知
- 聖地・イベント会場までの経路案内（地図アプリへの受け渡しもしない）
- 他人が登録した聖地情報の共有・聖地データベース化（次段階の公開投稿で扱う）
- 同じシーズンの再視聴の履歴（視聴日はシーズンに1つ）

## 5. 受け入れ基準
1. 未ログインでアプリを開くと、Apple でサインインする画面だけが表示され、記録画面には進めない
2. Apple でサインインすると、作品一覧（初回は「まだ作品がありません」と作品追加ボタン）が表示される
3. 設定からアカウント削除を実行し確認すると、サインイン画面に戻る。同じ Apple ID で再度サインインすると、作品・シーズン・各話の評価・聖地巡礼・グッズ・イベントの記録・写真が1件も残っていない。削除が途中で失敗したときは「削除できませんでした。記録は残っています」が表示され、サインイン画面へは戻らない
4. タイトル「すずめの戸締まり」・種別「映画」を入力して保存すると、作品一覧の先頭にその作品が視聴状態「観た」で表示される
5. タイトルが空のまま保存しようとすると保存されず、タイトル欄にエラーが表示される
6. 映画の作品詳細で評価4・感想・視聴状態「観た」・視聴日を保存し、アプリを終了して開き直すと、同じ内容が表示される
7. 評価を付けずに感想だけを保存できる（表示は「未評価」）。評価4を付けた後に「評価を外す」を選んで保存すると「未評価」に戻る（映画・シーズン・各話のどれでも同じ）
8. 作品詳細から聖地巡礼の記録を追加し、地図で位置を選び・場所名・日付・写真2枚・メモを保存すると、作品詳細の聖地巡礼の欄にその記録が表示される
9. 別の端末で同じ Apple ID にサインインすると、同じ作品・シーズン・各話の評価・記録・写真が表示される
10. 作品一覧で種別「アニメ」・視聴状態「観た」で絞り込むと、「作品ごと」表示では「観た」のシーズンを1つ以上持つアニメだけが、「シーズンごと」表示では「観た」のアニメのシーズンだけが表示される。一致が0件なら「条件に合う作品がありません」が表示される
11. 作品を削除しようとすると確認が表示され、確定すると、その作品のシーズン・各話の評価・感想・聖地巡礼・グッズ・イベントの記録と写真もすべて消える
12. 通信が無い状態で保存すると、「接続できません」が表示され、入力内容は画面に残る（黙って消えない）
13. 記録の読み込みに失敗したときは「読み込めませんでした」と再試行ボタンが表示され、「まだ作品がありません」とは表示されない
14. ある利用者の記録は、別の利用者のアカウントからは（URL・ID を知っていても）取得できない
15. 保存・削除のたびに、成功または失敗の通知が表示される
16. サインインしていない状態で、サインイン画面から利用規約とプライバシーポリシーを開ける
17. 作品詳細でタイトルと種別を変更して保存すると、作品一覧にも変更後の内容が表示される
18. 既に「すずめの戸締まり（映画）」がある状態で同じタイトル・種別を追加しようとすると「既に登録されています」が表示され、追加するかやめるかを選べる
19. 作品が0件の状態で、作品一覧の「＋」から「聖地を記録」を選び、その場で作品を新しく作って聖地巡礼の記録を保存すると、作品と記録の両方が作られる
20. 名前（場所名 / グッズ名 / イベント名）が空のまま記録を保存しようとすると保存されず、名前の欄にエラーが表示される。位置・写真・メモが空でも名前があれば保存できる
21. 位置情報の許可を拒否した状態でも、地図を手で動かして位置を選び、聖地巡礼・イベントの記録を保存できる。写真の許可を拒否した状態でも、写真なしで保存でき、設定アプリで許可する案内が表示される
22. 写真3枚のうち1枚のアップロードに失敗したときは「保存しました」が表示されず、失敗した写真に印が付き、再試行するかその写真を外すかを選べる
23. 種別「アニメ」で作品を追加すると、作品詳細に「シーズン1」が1つ表示される。映画にはシーズンの欄が表示されない
24. シーズン1に話数「12」を入力して保存すると、シーズン詳細に第1話〜第12話が並ぶ。話数を「13」に増やすと第13話が足される
25. 第3話にタイトル「南西へ」・評価5・一言感想を保存すると、第3話の行に「第3話 南西へ」と評価5が表示される。シーズンに手動評価がないときは、評価済み各話の平均も更新される
26. 作品詳細で「シーズンを追加」を選び、シーズン名「シーズン2」・話数「12」を保存すると、シーズン1の下にシーズン2が表示される。シーズン名が空のときは保存されずエラーが表示される
27. 第10話にタイトル・評価・一言感想のいずれかがある状態で話数を「8」に減らそうとすると、範囲外の話の記録が消える確認が表示される。やめると話数は12のまま残る
28. 作品一覧で「シーズンごと」に切り替えると、「進撃の巨人 シーズン1」「進撃の巨人 シーズン2」が別の行として表示され、映画は1作品1行のまま並ぶ。「作品ごと」に戻すと1行にまとまり、アニメ・ドラマの行には作品全体の評価・シーズン数・記録の件数が表示される
29. 作品詳細から「グッズを記録」を選び、グッズ名・写真1枚を保存すると、作品詳細のグッズの欄にその記録が表示される。グッズの記録には地図の欄が表示されない
30. 作品詳細から「イベントを記録」を選び、イベント名・日付・会場の位置・写真を保存すると、作品詳細のイベントの欄にその記録が表示される
31. アニメの作品を映画に変えて保存しようとすると「シーズンと各話の評価がすべて消えます」と確認が表示される。やめると種別はアニメのまま残る。確定すると映画になり、聖地巡礼・グッズ・イベントの記録は残る
32. 評価4・感想の付いた映画をアニメに変えて保存すると、「シーズン1」ができ、その評価4・感想・視聴状態・視聴日がシーズン1に表示される
33. シーズンが1つだけのアニメでは、シーズンの編集画面に「このシーズンを削除」が表示されない。2つ以上あるときは表示され、確認の後にそのシーズンと各話の評価が消える
34. 話数が 0 のシーズン詳細には「話数が入力されていません」と「話数を入力」ボタンが表示され、話数を入れて保存すると各話が並ぶ
35. シーズン1が評価4、シーズン2が評価5のアニメでは作品全体に「4.5（平均）」が表示される。作品全体を手動で評価3にすると3が表示され、「平均に戻す」と4.5に戻る。評価済みのシーズンが1つもないときは「未評価」と表示される
36. 未保存の入力または写真がある記録画面を、キャンセル、端末の戻る操作、またはスワイプで閉じようとすると破棄確認が表示される。やめると入力と写真が画面に残り、破棄すると記録もサーバー側の下書きも残らない。写真の一部アップロードに失敗した状態も同じ扱いになる
37. 保存済みの聖地巡礼・グッズ・イベントを編集するとき、名前・日付・写真・メモ・位置は変更できるが、記録の種類と紐づく作品は変更できない
38. 10MBを超える写真を選ぶと追加されず上限の案内が表示される。追加できた写真はアップロード前に長辺2048px以下へ縮小され、保存先の画像に位置情報を含むEXIFが残らない
39. 聖地巡礼の場所名を入力して約1秒待つと、最初に見つかった位置へ地図のピンが移動する。候補が見つからない、または検索に失敗した場合は案内と再検索ボタンが表示され、既存のピンを勝手に消さず、地図の手動選択と位置なしの保存を続けられる。検索中に地図を手動選択した場合は、遅れて返った検索結果で手動のピンを上書きしない
40. 写真と位置を持つ記録の詳細を開くと、保存した写真が順番どおりに表示され、保存した位置がピン付きの地図で表示される。グッズまたは位置なしの記録には地図を表示しない
41. 作品の追加または編集で10MB以下の画像を1枚選んで保存すると、作品一覧と作品詳細にその画像が表示される。画像は保存前に長辺2048px以下へ縮小され、位置情報を含むEXIFが残らない。画像を外して保存すると一覧と詳細は画像なしの表示へ戻る
42. 第1話が評価4、第2話が未評価、第3話が評価5のシーズンでは「4.5（各話の平均）」が表示される。シーズンを手動で評価3にすると3が表示され、「平均に戻す」と4.5に戻る。評価済みの話が1つもないときは「未評価」と表示され、作品全体の平均には各シーズンの表示評価が使われる

## 6. 完成の定義（Definition of Done）
- [ ] デプロイ先: App Store で公開（その前に TestFlight で本人の実機確認）
- [ ] 必要な環境変数・設定:
  - Supabase のプロジェクト URL・anon key（アプリに埋め込む値。service_role key はアプリに入れない）
  - Supabase の Apple サインイン設定（Services ID・Key ID・Team ID・秘密鍵）
  - 写真保存用のストレージバケットと、本人しか読み書きできないアクセス制御
  - Should を入れる場合: 作品データベース API のキー（アプリに直接埋め込むかサーバ経由かは plan mode で決める）
- [ ] 初回セットアップ手順: スキーマ初期化とマイグレーションを SQL ファイルとして持ち、新しい Supabase プロジェクトに順に適用すれば再現できる（適用は本人が行う）。アプリの初回ビルド手順は初回スキャフォールド後に README に記載
- [ ] App Store 提出物: プライバシーポリシーの URL、利用規約（または問い合わせ先）の URL、App プライバシー（収集するデータ：位置情報・写真・ユーザー ID）の申告
- [ ] 動作確認手順: TestFlight 版を実機に入れ、受け入れ基準 1〜42 を上から順に操作して期待結果になることを確認する。基準 9 は2台目の端末（またはアプリの削除→再インストール）で確認する

## 7. 決定済みの技術事項
- 実装方式は Expo SDK 57 + Expo Router + TypeScript。Windows の開発環境で扱え、前作と同じ構成を使えるため、2026-09-26 に決定した
- 評価は映画・シーズン・各話・作品全体の手動評価で共通して1〜5の整数とする
- アプリ名は「作品日和」、Bundle ID は `com.tiffanysho.sakuhinbiyori` とする。2026-10-04 に本人が公開用の値として確定した
- 開発ビルドだけ、動作確認用のメール／パスワードログインを表示する。本番UIのログインはAppleだけとする
- 検証コマンドは `npm run lint`、`npm run typecheck`、`npm test`、`npm run export:web` とする
- 写真付き記録は1件4枚までとし、1枚10MBを入力上限にする。アップロード前に長辺2048pxへ縮小し、位置情報を含むEXIFを除去する
- 作成後の写真付き記録では種類と紐づく作品を変更できない
- 写真の一部アップロードに失敗している間は記録を保存済みにせず、画面を閉じるときに破棄確認を出す。サーバー側の下書きは作らない

## 8. 未決事項
- 作品を最初から外部データベース（TMDB 等）に紐づけるか。今回は手入力を Must・検索を Should にしたが、次段階の公開投稿で「同じ作品」を束ねるには外部 ID があった方がよい。手入力の作品を後から外部 ID に紐づけ直す手段が要るかを決める
- 1シーズンの話数の上限（長期アニメで数百話になる場合の表示）
- 総集編・特別編・OVA など「第N話」の番号に当てはまらない話の扱い
- 1つのグッズ・イベントが複数の作品にまたがるとき（コラボグッズ・合同イベント）の扱い。今回は1記録＝1作品
- 作品全体の評価を導入した後、評価での並び替えを「作品ごと」と「シーズンごと」の両方で提供するか
- App Store 公開前に、Supabase 側の Email ログインを無効にするか。アプリから開発用UIを除いても、Supabase側で有効ならAPIからアカウントを作成できる
- 次段階（公開投稿）で必要になるもの：公開 / 非公開の切り替え単位（作品ごとか記録ごとか）、通報・ブロック（App Store のガイドラインでユーザー投稿には必須）、未成年への配慮。グッズの写真には他者の著作物が写るので、公開時の扱いも決める
