# 各話からのシーズン評価 実装計画

## 目的

評価済み各話からシーズン評価を自動算出し、各話を評価するだけでもシーズンと作品全体の評価を振り返れるようにする。対象は受け入れ基準25・35・42。

## 集計規則

- シーズンの手動評価を最優先する
- 手動評価がなければ、評価済み各話だけの算術平均を小数第1位へ四捨五入する
- 評価済み各話がなければ未評価とする
- 作品全体は、各シーズンの表示評価を同じ重みで平均する
- 自動算出値はDBへ保存せず、取得したデータから表示時に計算する

## 実装

1. 純関数へシーズン表示評価を追加し、作品全体の集計もそれを使う
2. シーズン詳細、作品一覧のシーズン行、シーズン評価編集へ自動平均を表示する
3. 手動評価を外す操作を「平均に戻す」として案内する
4. モックと説明文を新しい振る舞いへ合わせる
5. 単体テスト、型検査、Lint、Web書き出しを実行する

## データと移行

- 既存の `seasons.rating` を手動評価としてそのまま使う
- 各話評価は既存の `episodes.rating` を使う
- 列・制約・RLS・削除連鎖は変わらないため、DBマイグレーションは不要
- ロールバックは表示計算と文言を戻すだけで、既存データの変換は不要

## 非スコープ

- 未評価の話を0点として数えること
- 各話数で作品全体を重み付けすること
- 平均値をDBへ保存すること

## 検証

- 手動評価の優先、平均への復帰、未評価除外、小数第1位への丸めを確認する
- 各話の追加・変更・削除でシーズンと作品全体の表示が更新されることを確認する
- `npm run lint`、`npm run typecheck`、`npm test`、`npm run export:web`
